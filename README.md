## 1. Project Overview

### What is this project?

Briefly explain:
- What you built

Example:

This project simulates a small production infrastructure using multiple
Linux virtual machines. The environment consists of a reverse proxy,
application server, and database/DNS server.

The primary goal is to demonstrate fundamental Cloud/DevOps concepts
including Linux administration, networking, security hardening,
firewall configuration, service deployment, automation, health checks,
and infrastructure orchestration.

The entire environment is designed to be reproducible through
automation scripts rather than manual configuration.


## 2. Goals & Learning Objectives
